ENTREGA SEMANA 16 - RESTAURANTE APP

1. Copiar la carpeta restaurante_app a tu PC.
2. Abrir VS Code en la carpeta restaurante_app.
3. Abrir una terminal.
4. Ejecutar: python main.py
5. Ingresar con admin / admin123.
6. Entrar en Usuarios.
7. Probar Registrar, seleccionar una fila, Actualizar, Eliminar y Limpiar.
8. Probar Enter y Escape.
9. Cambiar el rol en el Combobox.
10. Subir toda la carpeta a un repositorio PÚBLICO de GitHub.
11. Entregar en Moodle únicamente el enlace del repositorio.
